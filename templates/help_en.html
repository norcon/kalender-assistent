How it works

The workflow

  1. Read emails: The app reads along in the mailbox. New emails are detected instantly, or at the latest every few minutes.
  2. Detect events: An AI on your own server looks for events in text, PDFs and images. These become suggestions – nothing is in the calendar yet.
  3. Review: On the start page, check title, date, time, location and the quote from the email. Everything can be changed by tapping it.
  4. Add: Tapping a calendar name adds the event to that iCloud calendar – including a reminder. The suggestion then moves to the archive. Which calendars are offered is set under Settings → Target calendars.

What the markers mean

Yellow border “Please check carefully”
The AI is unsure. Compare date and time with the quote in particular.
“Probably already in iCloud”
There is already an event with a similar name on the same day – maybe someone has added it already.
Red notice “Overlaps with …”
The chosen calendar already has an event at the same time. “… in iCloud: N events” shows what else is on that day.
“Possible duplicate”
A very similar suggestion already came from another email. Remove one of them.
Grey end time “(assumed)”
The email does not mention an end. The event is added with the configured default duration; tap to change.
“today”, “tomorrow”, “in 3 days”
When the event takes place – for a series, the next occurrence.
Quote marked “read from image/scan”
The quote comes from an image or scanned PDF and could not be matched word for word with the email.

Handy features

  • Filter and search: Above the list, filter by calendar or search by title, location and subject.
  • Several at once: Tick the boxes on the cards, then choose a calendar or “Remove” in the bar at the bottom.
  • Undo: After “Remove” or “Reject”, “Undo” briefly appears at the bottom.
  • Details: Set a calendar without adding the event, and see source and history under “Details” – or permanently via “Show all details”.
  • Advertising and parcel notices: If a sender keeps producing unsuitable suggestions, choose “Hide sender” on the card – for that one address or the whole domain. Future suggestions from there end up collapsed under “Hidden” at the very bottom. The list of senders is under Rules.
  • Newsletters: Suggestions from newsletters with uncertain detection also end up under “Hidden”. “Always show …” exempts a sender.
  • Calendar invitations: If an invitation (.ics) is attached to the email, the app takes the event exactly from it, without AI.
  • Reminder: Selectable on every card; “Default” uses the value from the settings.
  • Series: Under “Recurrence” you can set weekly, monthly etc. events with an end and exceptions.
  • Follow-up emails: If a later email changes or cancels an event, “Changes and cancellations to review” appears at the top. iCloud is only changed after you confirm. For a series, only the affected event is cancelled.
  • Reload: In the home-screen app, pull down from the very top. New versions are loaded automatically.
  • Light/dark: Switch at the top right – Automatic follows the device.
  • Language: The DE/EN button at the top switches the language on this device.

Getting something back

A removed or added suggestion
Find it in the archive and choose “Restore”.
An event deleted or changed in the calendar app
Under Backups → “Search and restore events”, click the moment in the change history when the event disappeared – it then appears under “Deleted” with a “Restore” button. The calendars are backed up regularly.
A hidden suggestion
At the very bottom of the start page, open “Hidden” and choose “Show”. Under Rules a sender can be allowed again completely.
Having an email analysed again
On a suggestion under “Details” → “Analyse email again”; for skipped emails directly in the list. The email is only read; nothing in the mailbox is changed.
The whole app back to an earlier state
Restore a database backup under Backups. The current state is backed up automatically first.

Status bar

Green = fine, yellow = notice, red = error, grey = not set up. When it is red, a look at the log often helps.

Where do I set what?

  • Mailbox, AI server, calendar server, notification channels (ntfy, Pushover, Home Assistant, email): Settings → Connections – shown as an overview at the top of the settings page.
  • How often mail is fetched, AI model, which events are reported: Settings.
  • Which calendars are written to: Settings → Target calendars.
  • Backups and updates: Backups.

Privacy

Emails are only read, never changed. Stored are suggestions with subject, sender and a short quote as the source passage – not the emails themselves. The emails are sent to the AI server configured under Settings → Connections; with a local AI everything stays in your home. Without a password for the interface the site has no login and should only be reachable on your home network.
